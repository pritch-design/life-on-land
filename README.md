# Life on Land — Welsh Baccalaureate A Level website

This is a static website made with HTML, CSS and a small amount of JavaScript. It is designed to be hosted for free using GitHub Pages.

## Files

- `index.html` — all website content and page structure
- `styles.css` — colours, layout, typography and responsive design
- `script.js` — mobile navigation menu

## Publish with GitHub Pages

1. Sign in or create a free account at https://github.com/.
2. Create a **new public repository**. A simple name is `life-on-land`.
3. Upload `index.html`, `styles.css` and `script.js` to the top level of the repository (not inside another folder).
4. Open the repository's **Settings**.
5. Select **Pages** in the left-hand menu.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose the `main` branch and the `/ (root)` folder, then select **Save**.
8. Wait a few minutes. GitHub Pages will show the published website address in the Pages settings.

The site address will usually look like:

`https://YOUR-USERNAME.github.io/life-on-land/`

Replace `YOUR-USERNAME` with your GitHub username.

## Editing

You can edit the text in `index.html` and the appearance in `styles.css`. Keep all three files together in the repository.

## Notes

- The website uses a remote Unsplash image for the main banner and Google Fonts for typography, so those visual elements require an internet connection.
- GitHub Pages is free for public repositories. The repository will be public, so do not upload private or identifying information.
- The supplied coursework text has been retained as provided. Check your final site against your own original document before submitting, especially any figures, references and access dates.
